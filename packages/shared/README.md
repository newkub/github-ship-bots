# @ship-feed/shared

Domain types and shared utilities for the ship-feed monorepo.

Contains `Env` types, `ShipCard` schemas, card mapping helpers, and crypto utilities used by `api`, `bot`, `orchestrator`, and `worker`.

## Scripts

| Script | Description |
| --- | --- |
| `lint` | Run `tsc --noEmit` |
| `test` | Run shared type and schema tests |
